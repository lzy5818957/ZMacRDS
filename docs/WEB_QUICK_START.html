ZMacRDS @VERSION@

把一台 Apple Silicon Mac（macOS 14.2 或更新版本）作为局域网桌面服务器。用户可在 Mac 或 Windows 上打开网页，使用这台 Mac 上已有的用户名和登录密码。

@SIGNING@

管理员首次设置

  1. 安装软件包，在「应用程序」里打开 ZMacRDS Manager。
  2. 在管理器点「启动网页服务」，确认自动填好的局域网地址、网段和端口，点保存并启动。默认同时连接 5 人，可在网页设置调至 32。容量取决于服务器资源。
  3. 点「复制网页地址」和「导出局域网证书」，把地址和公开证书交给客户端。每台客户端只需导入并信任一次。若已有与访问地址匹配的可信证书，在网页设置勾选「使用已有 HTTPS 证书」，导入 PEM 证书链及对应私钥。
  4. 每个要使用网页的账号先在服务器 Mac 登录一次，完成 macOS 的首次设置。然后在该账号的 ZMacRDS 管理器中打开「首次配置与权限」，开启录屏和键鼠，点「应用授权并重新检查」。管理员可以在管理器账号列表中确认两项均已授权。macOS 可能在首次播放声音时另行询问是否允许系统音频录制。
  5. 确认主页显示「网页服务运行中」，点「复制网页地址」发给用户。网页服务启动后会在服务器重启时恢复，点「停止网页服务」后则保持停止，直到手动启动。

用户怎么连接

在同一局域网打开管理员提供的 HTTPS 地址，输入已有的 Mac 用户名和密码。默认静音，点「开启声音」后播放音频；小字可用「原始大小」查看。已经登录 Mac 桌面的账号可直接连接。若要为尚未登录的账号按需建立桌面，管理员须在 macOS 屏幕共享中允许相应账号。

日常管理

管理器显示各账号的桌面、权限和网页连接。管理员可停止网页服务或断开某一账号，用户打开的应用会保留。建议给实体服务器预留固定的局域网地址；如需随时访问，请在 macOS 能源设置中防止系统自动睡眠。屏幕可以单独关闭。

正式部署可使用浏览器已信任的证书。若服务器更换局域网地址，重新打开「网页设置」并选择新地址。使用自动生成的证书时，已导入的根证书仍然有效。
