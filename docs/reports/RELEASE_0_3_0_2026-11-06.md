# ZMacRDS 0.3.0 交付验收

交付的是 Apple Silicon / macOS14.2+ 的可安装内部版本。服务器、桌面后台代理、原生管理窗口、首次配置、连接信息、运行环境和卸载入口合并为一个安装包；RDP 客户端配置、使用说明、校验和、第三方许可证及本报告随交付 ZIP 提供。没有把 Windows 实机、大规模容量或全新系统隐私授权计为通过。

## 软件行为

- 已登录账号各自运行桌面代理，按固定 UID 绑定画面、键鼠和应用声音。代理不限时运行，由 launchd 恢复；同账号新连接接管旧端，保留桌面应用。
- 菜单栏后台运行，无彩色诊断窗口。管理窗口查看账号、授权和连接状态，启动／停止／重启代理或系统 RDP 服务。
- 首次配置选择已有本地账号，自动生成每账号独立 RDP 口令和本机 TLS 身份。已有配置、口令和证书保留；当前配置页支持增加账号，最多8个，容量只实际验证了两个远程用户。
- 普通用户可查看自己的连接信息；其他账号、配置及系统服务操作需要独立的 macOS 管理员权利。权利五分钟失效，关窗撤销；密码由生产程序中的系统验证窗口处理，不写入软件配置。
- 本机回环 RDP 入口3390，经核对身份的安全隧道使用；原生 VNC 继续复用 macOS 屏幕共享。虚拟机的既有专用隧道保留。

## 实际安装验收

环境为 VM03，Apple Silicon、4核、8 GiB，系统标识沿用前轮记录。控制台UID504，远程账号UID505与506。宿主使用 Windows App 和苹果屏幕共享，没有可用的 Windows 操作系统客户端。

## 桌面和声音回归

最终安装包的两账号各完成20秒、9轮不同前缀中文文本。像素回执的UID与随机标记独立，接收文档与全部动作逐字一致。原始RDP测试客户端的“发送到解码文档回执”延迟：UID505中位206毫秒／P95 285毫秒；UID506中位215毫秒／P95 285毫秒，各9次。这不是 Windows App 最终呈现或公网性能数据。

此前相同采集实现的后台构建已完成两路65秒静止连接和241次状态采样，均无暂停；四秒进程停顿后两路40秒连接保持并恢复真实桌面。Windows App固定1920×1200远端、窗口本地缩放的六组放大／缩回共12张同步截图均完整。历史失败及修正过程见[后台管理报告](BACKGROUND_MANAGER_2026-11-05.md)。

音频、最终服务恢复及交付包复核结果由本轮日志单独记录；未将先前构建61分40秒长测当作本版本重新长测。合成测试源、编辑器和临时界面测试进程在交付前退出。

## 构建与交付边界

- Python3.13共55项测试通过；本项目RDP入口30项、检查器4项、NSCodec10项、vendor服务端18项及5项文档测试通过（另有1项文档示例跳过）。产品与NSCodec全目标严格clippy通过。
- 原生代码以 `-Wall -Wextra -Werror` 构建。安装包展开检查4504个载荷文件：没有实际测试凭据、运行配置或服务器私钥，运行时链接均留在载荷内，关键文件摘要及应用签名匹配。
- 应用使用稳定开发签名；安装包为内部交付，尚未做Developer ID公证。
- 默认RDP编码保留原始位图兼容回退，带宽成本较高；NSCodec仅显式试验。动态远端分辨率、Windows实机、更多用户及新版本长时稳定性仍待验收。
- 首次登录和系统录屏／辅助功能授权仍按macOS正常流程进行。实际锁屏、注销、休眠、无人登录时创建新Aqua桌面，以及无头／多显示器配置不能据此宣布通过。

软件安装使用见[使用说明](../QUICK_START.html)。

## 安装包版本的声音补充

两路各20秒，用实际AudioQueue生成的低音量375/750Hz源；核对所属UID、队列运行及非零生成帧后同时接收，不播放或保存接收PCM。UID505收到808,960立体声帧，隔离77.65dB；UID506收到857,600帧，隔离76.82dB，均通过实时帧数、最低信号幅度和40dB隔离门槛。初次把测试源幅度设得过低，虽有非零PCM和77dB以上频率比，仍被检查器的最低信号门槛拒绝；记录为失败。将源幅度调整为0.004后重跑通过，没有降低检查门槛。两组临时音源均已退出。

## 最终恢复补充

恢复原配置后的0.3.0安装版本又完成两路40秒静止连接；其中UID505进程暂停四秒后，在同一桌面身份和连接上恢复，过期约4秒的样本被明确丢弃，随后收到新的采集状态及真实桌面。UID506本轮没有暂停事件；两路最后行摘要均为实际桌面，未停留在暂停底色。
