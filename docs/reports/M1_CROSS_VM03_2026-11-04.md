# VM03 跨应用、中文输入与恢复实测

2026-11-04，`vm03-m1-cross-18` 已通过双向跨应用编辑、真实拼音与本地连接恢复验证。注销重登及权限撤销也已通过下方边界检查；结果仅适用于本次 VM03 单显示器配置，RDP 与其他显示配置另验。所有测试只涉及 VM03 两个合成测试账号。

## 配置与方法

macOS 27.2（26B123）、Apple Silicon、4 核、8 GiB、单个 1920×1200 虚拟显示器，ScreenCaptureKit 上限 2 fps。A 为 UID 502 / audit 100202，B 为 UID 503 / audit 100327。系统启动 ID 为 `35B0A7E4-B0FD-4BF4-BF14-36C6420C7A6D`。录屏和辅助功能通过正常系统设置授权，没有修改 TCC 数据库。

每个账号各有一个 M1Agent 和独立 M1Editor 进程；编辑器是普通 AppKit NSTextView。代理使用 `kCGSessionEventTap` 投递键鼠，不指定 PID，不通过脚本、辅助功能设置文字，也不直接写入编辑器文档。编辑器自行记录实际文档、鼠标选择、输入法组合及事件标签。Computer Use 只负责权限和物理控制台账号切换；正式输入由被测代理执行。

A 前台和 B 前台两个方向，每侧各做 100 次 Unicode 中文与 emoji 替换、真实鼠标选中文字，每十次往返切换应用焦点，并各做 3 次系统简体拼音的 `nihao` / `shijie` 组合提交。共 400 次主要编辑及 12 次拼音提交；每个编辑器各记录 66 次实际组合回调。全程没有跨账号事件或错误 UID / nonce 的解码帧。

## 结果

| 指标 | A | B |
| --- | --- | --- |
| 观测时长 | 622.004 秒 | 621.002 秒 |
| 心跳 / 有效解码帧 | 622 / 875 | 621 / 903 |
| 发送事件 | 1662 | 1732 |
| 编辑器或视图恰好一次接收 | 1622 | 1690 |
| 单独以焦点验证的激活事件 | 40 | 42 |
| 已接收事件最大 / p95 本机时延 | 33 / 20 ms | 37 / 19 ms |
| 显示器流重建 | 2 | 1 |

首次激活代理窗口的点击由 AppKit 处理，默认不传给 NSView 的 mouseDown / mouseUp。验证器只对此明确的 focus-agent 动作允许无视图回调，并要求 2 秒内成功的本账号焦点检查；其他事件仍要求恰好一次、类型和时延正确、另一账号零次。依据为 [Apple 鼠标事件说明](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/EventOverview/HandlingMouseEvents/HandlingMouseEvents.html)。验证器包含缺少焦点证明时必须失败的用例。没有改写原始日志。

两个账号在 A 前台共同持续获得本账号新像素 250.921 秒，在 B 前台为 241.917 秒（扣除切换宽限）。这些是有界实验，不代表性能或无限次会话切换验收。

A 显式断开 51 秒，代次从 1 变为 2；期间没有采集输出或输入投递，旧代次请求被拒绝。B 继续刷新并完成额外 10 次 Unicode 编辑。A 重连后代次为 3，原编辑器 PID 9987、nonce 与文档保留，再成功追加“，恢复成功”。该结果覆盖本地代理断开恢复，尚不是 RDP 网络重连。

## 诊断过程保留

`cross-14` 的 Unicode 文字正确，但拖动位置未落在文字上，选择长度为零；简体拼音父输入法未启用，选择失败。修正后 `cross-16` 可真实选中文字，拼音源也可选，但已打开的编辑器仍直接插入英文。对照虚拟机物理键盘可正常组合，随后重开编辑器（`cross-17`）后，前后台两侧被测代理均产生“你好世界”和实际组合回调。正式验收重新启动干净的 `cross-18`，保留此前失败日志，不把它们算作通过样本。

## 注销、重登与录屏撤权

`logout-19` 中在 A 的系统菜单执行真正注销（关闭重新打开窗口选项）。A 原代理及独立编辑器均退出，编辑器记录 `session_ended`；宿主机保存了注销前后的进程列表。B 原进程和 audit 100327 保持，A 离线、控制台为登录界面期间仍持续获得自身新像素，并完成三次中文编辑。

A 重新登录后，`newlogin-20` 的 audit 从 100202 变为 100671。分别重放完整旧请求、仅保留旧 audit 而更新 nonce / epoch 的请求，两者均在发送任何输入前被拒绝；使用当前身份的新请求成功完成三次编辑。B 在 A 重登后继续采集。

在 A 的系统设置关闭 `ZMacRDS-M1` 录屏权限时，macOS 明确提示应用退出前仍可录屏。不能声称切换开关即立刻撤销正在运行的流。完成系统的“Quit & Reopen”后，A 旧代理退出；`denied-21` 新进程持续记录 53 次心跳，录屏预检全部为否，采集返回 -3801，**零帧、零输入投递**，断开后的重连被拒绝。B 原代理仍持续采集本账号像素，没有被退出或切换为 A 的画面。权限按既有授权范围恢复后，`restored-22` 又得到本账号真实像素并正常结束（45 帧）。

边界证据在 `build/vm03-results/logout-19/`，包括旧、新身份与请求、进程列表、原始日志和 `boundary-verification.txt`。注销时系统终止进程，因此 A 旧日志不要求实验 stop 记录；常规完整批次仍必须有 clean stop。
