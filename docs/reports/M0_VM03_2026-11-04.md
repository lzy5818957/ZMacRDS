# M0 · VM03 双账号实测报告

2026-11-04（America/Los_Angeles），实验 `vm03-20261104-02` 返回 **PASS M0**，退出码 **0**。两名普通用户保持真实 Aqua 图形会话同时登录，在 A、B 分别处于前台时，两个 LaunchAgent 持续记录各自稳定且不同的用户与审计会话身份。

本结论仅涵盖 M0 会话身份。未测试桌面采集、键鼠投递、RDP 连接、Mac / Windows 客户端兼容或 32 人容量。

## 环境

| 项目 | 实测配置 |
| --- | --- |
| 虚拟机 | VirtualBuddy `ZBot-Mac-03` |
| 系统 | macOS 27.2，构建 26B123，arm64 |
| 资源 | 4 vCPU，8 GiB 内存 |
| 显示 | 单个虚拟显示器，配置为 1920 × 1200，110 PPI，自动调整分辨率关闭 |

| 录屏 / 辅助功能权限 | 两个代理的全部预检均为未授权；M0 不需要开启 |

## 执行方法

1. 将 M0 arm64 测试包安装到 VM03 的 `/Users/Shared/ZMacRDS-M0`。创建两个普通测试账号，分别通过 VirtualBuddy 图形界面登录并完成首次登录向导，进入 Finder 桌面；没有使用 SSH 登录替代图形登录。
2. 在各账号的菜单栏显示“快速用户切换”，保留管理员及两个测试用户的现有登录会话。
3. 使用管理员 SSH 通道，在已存在的真实 `gui/502`、`gui/503` 域中分别调用下面的命令。它与操作单中在用户 Terminal 输入启动命令的差异是启动入口；实际采样进程仍由各自 GUI 域中的 LaunchAgent 启动，以普通用户身份运行。

   ```sh
   launchctl asuser 502 sudo -H -u zmrds_a /Users/Shared/ZMacRDS-M0/m0 start vm03-20261104-02
   launchctl asuser 503 sudo -H -u zmrds_b /Users/Shared/ZMacRDS-M0/m0 start vm03-20261104-02
   ```

4. A 先采样，随后快速切换到 B、启动 B 采样。保持 B 前台，再快速切换并解锁 A，保持 A 前台；两个方向的共同观测时间均超过操作单要求的 15 秒。
5. 卸载两个临时 LaunchAgent，收集两份原始 JSONL、空的 stderr 日志、系统信息及验证结果。A 通过 `m0 stop` 停止，B 由管理员直接 `launchctl bootout gui/503/org.zmacrds.m0.vm03-20261104-02` 停止；随后核对两个服务均不存在且采样进程均已退出。
6. 在 VM03 内运行验证器，再将相同日志复制到宿主机，用同一版本验证器复核。两次均通过，输出一致。
