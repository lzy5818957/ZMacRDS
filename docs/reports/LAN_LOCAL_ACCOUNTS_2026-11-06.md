# 0.3.1 局域网直连与本地账号验收

版本：0.3.1，内部测试版。测试设备为原有 VM03（Apple Silicon、4 核、8 GiB、macOS 27.2 / 26B123）；客户端为宿主 Mac 上的 Windows App 与独立 RDP 协议验证器。没有可用 Windows 操作系统，本轮不宣称 Windows 实机验收通过。

## 本轮交付

- 安装后在 ZMacRDS Manager 点击“启动服务”，自动识别普通 Mac 本地账号。管理窗口提供启动、停止、重启、用户桌面登录状态、权限和 RDP 连接状态。
- 默认局域网 TLS RDP 入口为服务器 IPv4 地址的 3389 端口；界面可以修改端口、关闭直连、复制连接信息及导出不含密码的 RDP 文件。客户端不需要建立 SSH 隧道。
- 使用本机 `/Local/Default` 的 OpenDirectory 验证 Mac 登录密码。保留旧证书、私钥及回环 3390 入口；切换本地账号模式后，旧的独立测试口令不再用于认证。
- 普通用户只查看自己的状态；系统配置及其他账号管理沿用系统管理员验证。网络进程使用隐藏、不能登录的 `_zmacrds` 身份，各桌面桥接仍固定在对应 UID。
- 服务运行时每 30 秒同步本地账号变化。新增和删除账号无需手工编辑 RDP 配置；同步会重载网络服务，现有连接可能需要重连。

## 按需建立桌面与修复记录

已接入苹果本机屏幕共享的账号认证，用于建立已初始化用户的 Aqua 会话。Mac 密码仅在本机有界 IPC 与认证内存中使用，不写入配置、日志、进程参数或客户端连接文件。发送密码前，验证 5900 的监听进程为 root 所有的苹果系统屏幕共享程序。后续维持显示的辅助进程降权到目标用户，只继承已认证套接字，不接收密码；像素在内存中流式丢弃。

本轮修复了冷登录超时、原生显示初次刷新、代理重启后旧状态误判，以及 `launchctl bootout` 后立即 bootstrap 的短暂竞态。桌面就绪核对 LaunchServices 守护进程、实际代理 PID、UID、系统启动标识、正常隐私授权和实际采集时间，不仅依赖“capturing”布尔值。原生显示租约绑定用户的审计会话和系统启动标识，避免旧会话标记影响后来正常登录的新桌面。

从没有 GUI 域的 UID501 开始，实际常驻服务接收该用户的 Mac 密码，建立 Aqua 桌面并通过 RDP 返回真实内容。70 秒连接收到 204 次解码图形更新；并发 UID506 的 90 秒连接收到 341 次图形更新，均通过，未停留在暂停底色。随后加入会话租约绑定后的最终代码再次从无 GUI 域开始，70／90 秒测试分别收到 83／333 次图形更新，并核对租约的 UID、审计会话、系统启动标识及断线后的辅助进程退出。该账号此前已完成系统设置及隐私授权；这不是全新用户免授权实验。

同账号断开后再次连接 70 秒，收到 195 次图形更新；Aqua 审计会话保持不变，桌面代理可重新绑定。另以实际进程 UID 和已建立的本机 5900 TCP 连接验证辅助进程运行在目标普通用户下；断开后观察到该辅助连接自动退出。图形更新计数不等同于显示帧率。

早期候选构建发生过认证后无首帧、误读旧代理状态及原生等待超时，均记作失败，未通过降低验收条件掩盖。修正后才完成上述端到端验收；维护终端单独运行初始化成功未被当作常驻服务验收通过。

交付载荷展开检查：138 个仓库源文件、4504 个载荷文件通过已知实际测试凭据与服务器私钥扫描；关键文件摘要、应用及服务签名、运行时内部软链接检查通过。发布附件另提供 SHA-256 校验和。没有把私有运行目录、用户密码、VM 配置或服务器 TLS 私钥打入交付包。

## 使用边界

- 各用户首次 macOS 设置、录屏及辅助功能授权仍由系统要求；不能仅凭“账号存在”跳过。已登录并获授权的桌面可以直接使用 RDP。
- 自动建立尚未登录的用户桌面额外需要系统屏幕共享开启并允许该用户；苹果账号协议要求用户名和密码各不超过 63 个 UTF-8 字节。超出时先正常登录桌面，再连接 RDP。
- 只接受回环、RFC1918、链路本地和共享地址空间中的 IPv4 来源；不是公网网关，不自动配置路由器映射。系统防火墙规则只允许本软件，不关闭防火墙。“阻止所有传入”会明确报错；启用防火墙分支尚未在 VM03 实测，VM03 本轮防火墙为关闭状态。
- 当前证书为自签名，首次连接需要核对服务器显示的指纹；应用为内部开发签名，未进行 Developer ID 公证。
- 本轮网络路径验证器按固定 1920×1200 验收；未重做旧版本的音频隔离长测、中文输入与缩放压力矩阵。之前结果见随包历史报告，不把它们算作本轮重测。
- 未完成 Windows 操作系统客户端、服务器无人登录的整机冷启动、全新账号设置、大规模容量、动态远端分辨率和公网性能验收。128 个可发现账号及 16 条网络连接的实现上限不是并发容量承诺；低资源时拒绝新建桌面，保留已有会话。
