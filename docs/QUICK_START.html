ZMacRDS 0.3.2

Mac 多用户远程桌面 · 局域网直连内部测试版

服务端要求 Apple Silicon Mac、macOS 14.2 或更新。客户端只需 RDP 软件，输入服务器 IP、Mac 本地短用户名和该账号原有的 Mac 登录密码。默认端口 3389，不需要客户端 SSH 隧道。

服务器首次使用

  1. 双击 ZMacRDS-0.3.2-arm64.pkg 完成安装，打开应用程序中的 ZMacRDS Manager。当前内部包未公证；若系统拦截，在“系统设置 → 隐私与安全”核对文件后点该安装包的“仍要打开”。无需关闭全局安全检查。
  2. 点击 启动服务，完成系统管理员验证。软件自动识别这台 Mac 已有的普通本地用户、建立后台服务，并显示服务器局域网 IP；不需要逐个添加 RDP 账号或另设连接口令。
  3. “首次配置与权限”窗口集中显示服务、本账号的录屏／系统音频和远程键鼠状态。依次点两项设置按钮，在系统设置中开启 ZMacRDS Desktop。键鼠权限在新版 macOS 称为“设备控制和数据访问”，旧版称为“辅助功能”。若录屏授权提示退出，可先选“以后”，完成两项后回到向导点 应用授权并重新检查，统一重新加载本账号代理；已连接的本账号 RDP 会中断，桌面应用保留。无需授予麦克风、摄像头或完全磁盘访问。
  4. 服务器保持唤醒，各账号使用“切换用户”保留桌面。如需让 RDP 为尚未登录的用户启动桌面，在“首次配置与权限”中点“系统屏幕共享设置…”，开启苹果“屏幕共享”并允许这些用户。RDP 会使用刚输入的正确密码，经本机苹果服务建立该用户的独立桌面；不保存密码。未开启时，先正常登录用户桌面即可。

首次启动自动创建隐藏、禁止密码登录且不能打开终端的专用后台工作身份 _zmacrds，它不作为远程桌面用户。Mac 登录密码由本机 OpenDirectory 验证，不保存在本软件配置或日志中。自动桌面登录只针对已初始化且获系统屏幕共享访问许可的本地账号，不绕过锁屏、首次设置或系统隐私授权；第一次建立桌面可能需要几十秒。

安装包为内部交付，应用使用开发签名，尚未进行 Developer ID 公证。通过交付的 SHA-256 文件核对内容。

Mac 和 Windows 如何连接

项目填写内容
服务器／PC 地址管理窗口显示的 IP，例如 192.168.1.50。使用默认端口 3389 时无需填写端口。
用户名Mac 本地短用户名，例如 alice，不是 Apple 账号邮箱。
密码该用户原有的 Mac 登录密码。升级前的独立 RDP 测试口令不用于本地账号模式。

Mac 使用 Windows App 添加 PC；Windows 可使用系统“远程桌面连接”（mstsc）。也可以在服务器管理窗口选中账号 → “连接信息…” → “导出 RDP 文件…”，把不含密码的文件交给该用户，双击打开。

RDP 固定远端 1920×1200，开启客户端本地缩放，关闭“调整窗口时更新会话分辨率”。声音选择“在此电脑播放”。首次连接自签名证书时，与服务器“连接信息…”中的 SHA-256 指纹核对。Windows 操作系统客户端尚未实机验收；Mac Windows App 及自动协议客户端的验证范围见测试记录。

管理服务

  • 启动服务／停止服务：管理整个 RDP 入口，停止会断开客户端，保留 Mac 用户桌面和应用。
  • 用户列表：显示已登录 Mac 的用户、尚未登录桌面的账号、录屏／键鼠授权及当前 RDP 连接。普通用户默认只看自己；本地管理员或完成管理员验证后可查看全部。
  • 首次配置与权限…：可随时重新打开集中检查窗口；权限由各个 Mac 账号分别授予，管理员不能代替其他用户全局授权。状态以代理实际预检和采集结果为准，系统设置中的开关已开启但未重载时不会提前显示就绪。
  • 连接设置…：允许或关闭局域网直连、修改端口。非默认端口需使用 IP:端口。端口占用时拒绝保存，保留原有服务。
  • 连接信息…：查看地址、用户名、证书指纹，复制说明或导出不含密码的 RDP 文件。不会显示 Mac 登录密码。
  • 新增本地用户：在 macOS 系统设置创建账号即可；服务运行时每30秒检查账号变化，自动安装该用户的代理。账号变化会重新装载 RDP 服务，现有客户端可能需要重连；首次桌面初始化与系统授权仍必须完成。
  • 同账号新的正确 RDP 登录接管旧连接，桌面保留；错误密码不会踢掉正确连接。不同用户的桌面、输入和音频按 UID 隔离。

网络范围与旧版升级

直连支持同一局域网或可路由的私有 IPv4 网络，默认监听 3389，只接受回环、私有网络及链路本地地址。局域网隔离、防火墙“阻止所有传入连接”、路由和 VPN 策略仍需允许访问。软件只允许自身的防火墙应用规则，不关闭系统防火墙，不配置路由器公网映射。

升级 0.3.0 时先保留原有设置、证书和旧连接方式。点击“启动服务”后切换到本地 Mac 密码模式，并自动识别所有普通本地账号。回环 127.0.0.1:3390 入口继续存在，03 的既有安全隧道也保留；新客户端直连不依赖它。

可选 VNC

VNC 仍由 macOS 的原生“屏幕共享”提供，可在“系统设置 → 通用 → 共享”启用并允许对应用户。其他 Mac 的屏幕共享可连接 vnc://服务器IP，使用 Mac 本地用户名与密码。Windows VNC 客户端须支持 Apple 用户名／密码认证，目前没有完成 Windows 实机兼容验收；已登录桌面的 RDP 连接不依赖屏幕共享；自动登录尚未启动的用户桌面需要这项系统服务。自动初始化的苹果账号协议限制用户名和密码各不超过63个 UTF-8 字节，超出时可先正常登录桌面再使用 RDP。

卸载与已知边界

运行随包的“卸载 ZMacRDS.command”，确认后使用管理员验证。停止本软件服务并移除应用，保留本地账号、文档、私有配置、证书及已有隧道；重新安装可沿用设置。后台服务身份也保留供重装使用。

当前为内部测试版，实际并发验收仍以两个远程用户加控制台用户为准。未完成 Windows 实机、公网性能、大规模容量、动态远端分辨率，以及无人登录的冷启动／全新用户首次设置的完整验收。已有初始化账号的苹果原生桌面创建路径已在03验证，仍要求系统屏幕共享访问许可及已完成的隐私授权。默认原始位图兼容回退带宽较高。真正锁屏、注销和休眠仍服从 macOS 的系统行为。
